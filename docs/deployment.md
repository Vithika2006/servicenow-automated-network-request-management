# Deployment / PDI Implementation

## Order
1. Create/verify application scope and roles.
2. Create u_network_request and typed fields.
3. Create Network category and catalog item.
4. Create reusable user-context variable set.
5. Add catalog variables.
6. Configure Catalog UI Policies and required Client Scripts.
7. Configure ACLs.
8. Configure Flow Designer and approvals.
9. Configure notifications.
10. Configure reports.
11. Execute the test matrix.
12. Complete UAT.
13. Package approved configuration using the organization's update-set/application deployment process.

## PDI checklist
- [ ] Catalog item visible
- [ ] Variables render
- [ ] Conditional fields work
- [ ] User context populates
- [ ] RITM created
- [ ] Network Request created
- [ ] Approvals created
- [ ] Rejection stops fulfillment
- [ ] Approval continues fulfillment
- [ ] Notifications delivered
- [ ] ACLs verified
- [ ] State transitions verified
- [ ] Audit verified
- [ ] Reports verified

This repository cannot itself verify ServiceNow runtime behavior.
