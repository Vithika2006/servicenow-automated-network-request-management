# Interview / Demo Walkthrough

## What
Automated Network Request Management standardizes network request intake, approval, fulfillment and tracking.

## Why
It reduces manual routing, improves data quality, provides an auditable approval trail and improves requester visibility.

## How
1. Open Service Portal.
2. Navigate to Network Services → Network Request.
3. Fill request details.
4. Demonstrate Existing connection and conditional Existing ID.
5. Submit.
6. Show RITM and Network Request record.
7. Show Flow Designer execution.
8. Show approval.
9. Approve and show fulfillment assignment.
10. Show notification and audit history.
11. Complete fulfillment and show Completed.

## Interview talking points
- RITM remains the standard catalog transaction.
- Custom record stores network-specific operational data.
- Flow Designer orchestrates automation.
- Approval routing is dynamic rather than user/sys_id hard-coded.
- ACLs implement least privilege.
- Runtime testing is demonstrated from actual PDI evidence.
