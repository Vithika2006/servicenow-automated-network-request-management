# Troubleshooting

## Flow did not trigger
Check flow active state, catalog item trigger, RITM creation and Flow Designer Execution Details.

## Catalog variable is empty
Check variable name vs label, Get Catalog Variables configuration, and catalog client/UI policy behavior.

## Approval not created
Check Requested For, manager/group resolution, approval action target and flow execution details.

## Email missing
Check notification conditions, recipient resolution, email logs, active state and PDI email configuration.

## ACL blocks expected user
Check required role, table/field ACL evaluation, record ownership and impersonation.

Remove temporary debug logging before production use.
